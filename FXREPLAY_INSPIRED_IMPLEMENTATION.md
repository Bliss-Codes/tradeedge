# FXReplay-inspired TradeEdge polish

Implemented only presentation-level improvements inspired by the supplied
FXReplay screenshots.

## Adopted
- Controlled analytics content width and centered layout
- Clear Analytics page header
- Quiet filter bar with divider treatment
- Consistent section rhythm
- Consistent card radius and internal padding
- Stronger title hierarchy
- Balanced Performance by Side chart area
- Consistent Performance by Session card footprint
- More breathing room around charts
- Tighter, more structured month/grid presentation
- Restrained positive/negative emphasis

## Intentionally not copied
- FXReplay branding
- FXReplay colors
- FXReplay navigation structure
- Any proprietary data behavior

## Safety boundary
No Supabase files, persistence code, trade calculations, account logic, or
analytics formulas were modified. Changes are limited to the Analytics page
layout and visual CSS.
