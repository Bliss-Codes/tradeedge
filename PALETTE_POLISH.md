# Palette polish

Based on the supplied reference, this keeps the existing TradeEdge UI intact
and adds only restrained touches:

- #06231D deep green for subtle emphasis
- #076653 green for active/positive accents
- #E2FBCE soft green for light-theme selected states
- #E3EF26 lime used sparingly as a small highlight
- #FFFDEE warm white available for tiny light-theme highlights

No broad recolor, no new colored card backgrounds, and no redesign of the
existing visual system.
