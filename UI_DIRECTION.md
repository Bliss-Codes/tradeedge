# Refined UI direction

The previous UI structure is preserved. This iteration removes the overly
colorful palette treatment and returns to a restrained premium dashboard:

- neutral dark/white surfaces
- one controlled green brand accent
- muted borders and typography
- green reserved for active states, positive values and key actions
- no lime backgrounds across cards
- no multi-color decorative gradients
- portrait avatars remain available only inside the avatar picker

This is presentation-only; no Supabase, persistence, trading logic, account
logic, or analytics calculations were changed.
